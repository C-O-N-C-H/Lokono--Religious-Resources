# Lokono Religious Resources: Aligned Biblical Texts

## Overview

This repository hosts a significant corpus of religious texts translated into the Lokono (Arawak) language, primarily focusing on portions of the Bible. It is believed to be the largest available collection of text in the Lokono language.

The Lokono translation presented here dates back to **1856** and is believed to have been based on the King James Version (KJV) of the Bible. Due to its age, the copyright on the original 1856 Lokono translation has expired, placing it in the public domain.

The primary contribution of this repository is the meticulous **verse-by-verse alignment** of the historical Lokono text with the corresponding English KJV text. This was undertaken because the original Lokono manuscripts, while in the public domain, were previously held in a repository that made direct download and comparative use challenging.

## Purpose

The goal of this project is to:

- Provide an accessible, digitally formatted version of these important Lokono texts.
- Facilitate study, research, and revitalization efforts for the Lokono language.
- Enable easier comparison and translation work between Lokono and English for linguists, researchers, community members, and translators.
- Serve as a valuable dataset for natural language processing (NLP) applications and tool development for the Lokono language.
